# Middleware — Analysis & Design Tracker

This folder is the living design record for the open-source **SangamMW** middleware project.

## Purpose
Build a production-grade, open-source middleware that provides a unified connector/adapter layer, pipeline orchestration, and data processing engine — extracted from and generalising the patterns in AgentStudio and eInsta.

## Files

| File | What it is |
|---|---|
| `v0.1-initial-plan.md` | First full architecture proposal (derived from codebase analysis) |
| `OPEN_QUESTIONS.md` | Unresolved design decisions — things to debate before locking v0.2 |
| `VERSIONS.md` | Version index with summary of what changed in each iteration |

## Conventions
- Every version is a new numbered file (`v0.N-<slug>.md`). Never edit a past version.
- Resolved debates move from `OPEN_QUESTIONS.md` into the next version's decision log.
- Use `VERSIONS.md` as the table of contents.
